# /deploy -- no web deploy

**Claudia has no web deploy.** Its README on GitHub -- https://github.com/mindattic/Claudia -- is the project page. To update the project page, edit `README.md` and push to `main`. Do not run MindAttic.Deploy for this project.

The README is static. Its parts and build-options tables are written by hand from `config/parts.json`; when the catalog changes, update those tables by hand.

When invoked, tell the user the above and stop.
